# PCA 차원 선택 기록

이 문서는 AG News 768차원 임베딩에서 클러스터링과 UMAP 시각화에 사용할
PCA 차원을 선택한 과정과 결과를 보존한다. 분석 작업 트리는 이후 제거하지만,
아래의 기준과 수치는 `main`에 남긴다.

## 현재 기본 파이프라인

현재 `main`의 기본 경로는 고정된 PCA 차원을 사용하지 않고 자동 선택기를
호출한다.

- 클러스터링: 자동 선택, 기본 후보는 **PCA-32, 64, ... 최대 512**
- UMAP 시각화: 자동 선택, 기본 후보는 **PCA-16, 32, ... 최대 512**
- 두 선택기 모두 실제 입력에서는 `min(최대 후보, 샘플 수, 임베딩 차원)`까지
  후보를 줄인다.
- 선택된 PCA 변환기와 실제 선택 차원은 결과 트리와 상태 파일에 저장된다.
- 정수를 `--pca-components` 또는 `--visual-pca-components`로 지정하면 자동
  선택을 끄고 해당 차원을 고정한다.

클러스터링 선택기는 원본 정규화 임베딩과 정규화된 PCA 접두 부분의 k-NN 보존율을
비교한다. 후보 차원이 증가할 때 평균 보존율 증가량이 처음으로 기본
`0.05` 미만이 되면 직전 차원을 선택하고, 끝까지 기준을 만족하면 최대 후보를
선택한다. 따라서 클러스터링의 기본 최소 후보는 32이며, 16차원을
클러스터링 기본값으로 사용하지 않는다. 단, 임베딩 차원이 32보다 작으면
입력 차원까지 안전하게 줄여 평가한다.

시각화 선택기는 각 PCA 접두 부분을 같은 설정의 UMAP-2에 통과시킨 뒤 원본
임베딩과 UMAP 좌표의 k-NN 보존율 증가량으로 같은 규칙을 적용한다. 선택된
접두 부분으로 UMAP을 학습하고, 이후 온라인 `transform`에도 동일한 접두
부분을 재사용한다.

## 과거 고정 차원 평가

이 절의 수치는 AG News 768차원 임베딩에서 고정 후보를 비교한 과거
평가 결과를 보존한다. 현재 운영 기본값은 위 자동 선택 알고리즘이다.

- 당시 평가 결론: 클러스터링 **PCA-256**
- 당시 평가 결론: UMAP 시각화 **PCA-64 -> UMAP-2**
- UMAP 소프트 목표: 정규화된 소프트 클러스터 소속도 4차원,
  `target_weight=0.01`

클러스터링은 원본 공간의 정보와 이웃 구조를 더 많이 유지하도록 256차원을
사용한다. UMAP은 2차원으로 다시 압축되므로, 64차원에서 속도와 구조 보존의
균형을 잡는다.

## 평가 방법

모든 비교에서 다음 조건을 고정했다.

- 입력: 4,000개, 원본 임베딩 768차원
- PCA 입력: L2 정규화된 원본 임베딩
- UMAP: `n_components=2`, `n_neighbors=15`, `min_dist=0.02`,
  `metric=cosine`, `spread=0.85`, `densmap=False`
- UMAP 시드: 42 (차원 간 직접 비교)
- 이웃 비교: 각 점의 k-NN 집합에 대해 `|교집합| / k`와 Jaccard 계산
- k 값: 15, 30

PCA-16/32/64의 초기 선택에서는 시드 11, 42, 73을 사용해 UMAP을 반복하고,
로컬 이웃 보존율·전역 거리 순위 상관·시드 간 이웃 그래프 안정성을 측정했다.
최고 평균의 1표준오차 안에 드는 가장 작은 차원을 선택하는 규칙을 사용했다.

## 누적 설명 분산

정규화된 768차원 임베딩에 전체 SVD PCA를 적용한 값이다.

| PCA 차원 | 누적 설명 분산 |
|---:|---:|
| 16 | 31.87% |
| 32 | 45.30% |
| 64 | 61.57% |
| 128 | 79.09% |
| 256 | 92.96% |

## 원본과 PCA 공간의 최근접 이웃

`intersection/k` 기준이다. PCA 차원이 커질수록 원본 이웃 보존율이
일관되게 증가한다.

| 차원 | k=15 | k=30 |
|---:|---:|---:|
| PCA-16 | 36.51% | 43.32% |
| PCA-32 | 53.12% | 59.23% |
| PCA-64 | 68.14% | 72.42% |
| PCA-128 | 80.82% | 82.72% |
| PCA-256 | 87.17% | 87.82% |

## 원본과 UMAP-2의 최근접 이웃

UMAP으로 2차원까지 압축하면 차원 증가 효과가 크게 줄어든다. 그래도
PCA-16에서 64로 올릴 때는 개선이 분명하고, 128/256은 64보다 소폭만
개선된다.

| UMAP 입력 PCA | k=15 | k=30 |
|---:|---:|---:|
| PCA-16 | 21.59% | 27.72% |
| PCA-32 | 28.59% | 34.66% |
| PCA-64 | 31.20% | 36.85% |
| PCA-128 | 32.32% | **37.13%** |
| PCA-256 | **32.36%** | 37.04% |

PCA-128/256의 UMAP 결과가 PCA-64보다 약간 높지만, PCA-256의 추가 비용에
비해 UMAP-2의 이웃 보존 이득은 작다. 따라서 시각화 기본값은 PCA-64로
정했다. PCA-16과 32는 이웃 구조 손실이 더 커서 기본값으로 선택하지 않았다.

## UMAP 결과끼리의 이웃 비교

각 차원으로 생성한 UMAP-2 좌표의 k-NN 집합을 직접 비교한 결과다.

| 비교 | k=15 | k=30 |
|---|---:|---:|
| UMAP-16 vs UMAP-32 | 28.36% | 37.15% |
| UMAP-16 vs UMAP-64 | 22.25% | 29.75% |
| UMAP-32 vs UMAP-64 | 37.19% | 47.59% |

UMAP-16은 UMAP-64와 특히 다르다. UMAP-32와 64도 완전히 같은 결과는
아니지만, 16보다는 서로 가깝다.

## 해석과 한계

설명 분산만으로 클러스터링 차원을 결정하지 않았다. 당시 PCA-256은 해당
데이터에서 92.96%의 분산과 가장 높은 원본 이웃 보존율을 보였다. 현재는 이
평가 규칙을 데이터마다 재실행해 임베딩 모델이나 노트 집합이 바뀌어도
차원을 다시 선택한다.

시각화 차원 선택은 UMAP의 성격에 맞춰 로컬 이웃 보존율을 1차 기준으로 삼았다.
UMAP은 매번 재학습하지 않고, 선택한 PCA와 UMAP 모델을 저장해 온라인에서는
변환만 수행해야 한다.
