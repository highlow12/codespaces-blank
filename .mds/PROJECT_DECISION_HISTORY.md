## 1. 발표 요약

### 1.1 한 문장 소개

본 프로젝트는 **텍스트 임베딩의 의미적 방향과 문서의 복합적인 주제 소속을 보존하면서, 계층형 군집 구조를 생성하고 지속적으로 갱신할 수 있는 소프트 클러스터링 및 시각화 시스템**이다.

### 1.2 해결하려는 문제

일반적인 하드 클러스터링은 문서 하나를 클러스터 하나에만 배정한다. 하지만 실제 문서는 여러 주제를 동시에 포함할 수 있으며, 주제 또한 대분류와 소분류의 계층 구조를 가진다. 데이터가 추가될 때마다 전체 시각화가 바뀌면 사용자는 기존 지도의 위치 관계도 다시 학습해야 한다.

본 프로젝트는 다음 세 문제를 함께 해결하고자 했다.

1. 문서의 **복합적인 의미 소속**을 어떻게 보존할 것인가?
2. 평면적인 클러스터를 **데이터 적응형 계층 구조**로 어떻게 확장할 것인가?
3. 새 문서가 추가되어도 기존 사용자의 **시각적 심상 지도**를 어떻게 유지할 것인가?

### 1.3 핵심 해결 방법

```text
텍스트 임베딩
  → L2 정규화
  → PCA 차원 축소
  → 구면 퍼지 C-Means
  → 데이터 적응형 재귀 분할
  → 조건부 경로 소속도 계산
  → 약지도 UMAP 시각화
  → 고정 좌표 기반 증분 업데이트
```

### 1.4 핵심 성과

- 비교 실험에서 `PCA64 + FCM`이 NMI `0.5651`, ARI `0.5998`로 가장 균형 잡힌 성능을 보였다.
- UMAP+HDBSCAN의 높은 실루엣이 실제로는 49~57개 클러스터의 과분할과 최대 29.4% 노이즈를 동반한다는 점을 확인했다.
- 하드 라벨뿐 아니라 평면·계층별 소프트 소속도를 저장하도록 확장했다.
- 서로 다른 부모 아래의 소속도를 직접 비교하지 않고 조건부 경로 확률로 표현했다.
- 신규 배치의 노이즈 비율이 기준을 넘을 때만 전체 재군집화하는 증분 구조를 구현했다.
- PCA 차원을 설명분산뿐 아니라 k-NN 보존, 거리 상관, 시드 안정성으로 정량 평가했다.

## 2. 프로젝트 배경과 문제 정의

### 2.1 텍스트 임베딩 군집화의 특성

텍스트 임베딩은 문장의 의미를 고차원 벡터로 표현한다. 이때 의미적 유사성은 벡터의 크기보다 방향에 더 강하게 반영되는 경우가 많다. 또한 문서 한 개가 스포츠와 경제, 기술과 사회처럼 여러 의미 영역에 동시에 걸칠 수 있다.

따라서 다음과 같은 한계가 발생한다.

- 하드 클러스터링은 두 번째로 가능성 높은 주제를 버린다.
- 평면 클러스터 ID는 대주제와 소주제의 관계를 표현하지 못한다.
- 2차원 시각화가 보기 좋더라도 원래 고차원 구조를 왜곡할 수 있다.
- 새 데이터를 넣을 때 전체 지도를 다시 계산하면 기존 좌표가 모두 움직인다.

### 2.2 연구 질문

본 프로젝트의 연구 질문은 다음과 같다.

> 고차원 텍스트 임베딩의 의미적 모호성을 제거하지 않으면서, 사람이 이해할 수 있는 계층 구조와 안정적인 2차원 지도로 변환할 수 있는가?

이를 세부 질문으로 나누면 다음과 같다.

- 어떤 군집 알고리즘이 의미 보존, 노이즈, 과분할, 실행시간 측면에서 균형적인가?
- 계층별 소속도를 어떻게 정의해야 수학적으로 일관되는가?
- 군집 결과를 시각화에 어느 정도 반영해야 구조를 과장하지 않는가?
- 증분 데이터가 들어올 때 언제 기존 모델을 유지하고 언제 재학습해야 하는가?

## 3. 연구 목표와 핵심 설계 원칙

### 3.1 의미의 모호성 보존

최종 클러스터 하나만 저장하지 않고 각 클러스터에 대한 소속도 전체를 보존한다. 하드 라벨은 화면 표시와 요약에만 사용한다.

### 3.2 임베딩의 방향성 보존

입력과 FCM 중심을 단위 구면에 유지한다. 정규화된 벡터에서는 유클리드 거리와 코사인 유사도의 순위가 대응하므로, 구현은 단순하게 유지하면서 방향 기반 의미 공간을 보존할 수 있다.

### 3.3 군집화와 시각화의 분리

군집화는 고차원 의미 구조를 찾는 문제이고, UMAP은 그 결과를 사람이 볼 수 있게 표현하는 문제다. 2차원에서 잘 분리되어 보인다는 이유만으로 군집 알고리즘을 선택하지 않는다.

### 3.4 데이터가 지지하는 만큼만 계층화

모든 노드를 같은 깊이와 같은 자식 수로 강제하지 않는다. 각 노드에서 후보 `k`를 다시 평가하고, 분할 품질이나 표본 수가 부족하면 재귀를 중단한다.

### 3.5 운영 중 시각적 안정성 유지

신규 문서는 저장된 모델로 배정하고 새 좌표만 추가한다. 분포 변화가 충분히 클 때만 전체 군집을 다시 계산한다.

### 3.6 정량 근거에 기반한 선택

단일 지표나 시각적 인상에 의존하지 않고 NMI, ARI, 실루엣, 노이즈, 파편화, 이웃 보존, 거리 상관과 안정성을 함께 평가한다.

## 4. 전체 시스템 구조

### 4.1 군집화 파이프라인

```text
원본 임베딩
  → L2 정규화
  → PCA
  → PCA 결과 L2 정규화
  → 구면 FCM
  → 후보 k 평가
  → 노이즈 및 작은 자식 제거
  → 유효한 자식에 대해 재귀 반복
```

구면 FCM에서는 각 반복마다 소속도를 사용해 중심을 계산한 뒤 중심을 다시 단위 구면으로 정규화한다. 이를 통해 중심도 입력과 같은 의미 공간에 유지한다.

### 4.2 계층 분할 조건

각 노드에서는 다음 조건을 확인한다.

- XB 최초 악화 후 K를 2번 더 확인하고 XB 50%·PC 25%·PE 25% 순위점수로 선택
- 최소 노드 크기와 최소 자식 크기
- 최소 분할 실루엣
- 소속도 임계값
- 중심 거리의 중앙값/MAD 기반 이상치 판정
- 최대 계층 깊이

분할 근거가 부족하면 해당 노드는 리프로 남는다.

### 4.3 계층형 소프트 소속도

같은 부모 아래의 FCM 소속도는 해당 부모 내부의 조건부 확률로 해석한다.

```text
P(1-2) = P(1) × P(1-2 | 1)
```

서로 다른 부모에서 독립적으로 계산된 지역 소속도를 직접 비교하지 않고, 부모까지의 확률을 곱한 경로 소속도를 저장한다. 이를 통해 같은 깊이의 경로들을 일관된 기준으로 비교할 수 있다.

### 4.4 시각화 파이프라인

```text
원본 임베딩
  → L2 정규화
  → 시각화용 PCA
  → L2 정규화
  → 소프트 소속도를 약한 목표로 사용한 UMAP2
  → 계층 경로에 따른 색상과 라벨 표시
```

- 대주제는 서로 다른 색조를 사용한다.
- 같은 대주제의 하위 클러스터는 유사한 색 계열을 사용한다.
- 계층 경로는 `3-2-4`와 같은 형식으로 표현한다.
- 실제 범주 이름보다 발견된 클러스터 구조를 중심으로 표시한다.

### 4.5 증분 업데이트

```text
신규 문서
  → 기존 PCA 변환
  → 저장된 FCM 중심에 배정하고 중심 온라인 업데이트
  → 기존 UMAP 모델로 신규 좌표만 변환
  → 주기적으로 전체 소속도와 계층 가중 XB 재계산
      ├─ XB 악화 5% 미만: 갱신된 중심과 기존 좌표 유지
      └─ XB 악화 5% 이상: 누적 데이터 전체 재군집화
  → 신규 배치 노이즈 5% 초과 시 즉시 전체 재군집화
```

전체 재군집화 이후에도 시각화 PCA·UMAP과 좌표는 유지한다. 증분 UMAP에서는
신규 점 변환을 지원하지 않는 densMAP을 비활성화한다.

## 5. 핵심 기술 선택과 근거

### 5.1 PCA + FCM을 선택한 이유

초기에는 다음 방법을 비교했다.

- 원시 FCM
- PCA64 + FCM
- PCA64 + HDBSCAN
- PCA50 → UMAP2 → HDBSCAN
- UMAP8 → HDBSCAN
- PCA64 + GMM

PCA는 고차원의 잡음과 계산량을 줄이고, FCM은 각 문서의 소속도 전체를 제공한다. 이 조합은 외부 라벨 정합성, 클러스터 수, 노이즈와 실행시간을 함께 고려했을 때 가장 균형적인 결과를 보였다.

### 5.2 HDBSCAN을 주력으로 선택하지 않은 이유

HDBSCAN은 클러스터 수를 미리 정하지 않아도 되고 노이즈를 분리한다는 장점이 있다. 그러나 실험에서는 다음 문제가 나타났다.

- PCA64+HDBSCAN: 39.0%의 높은 노이즈
- UMAP+HDBSCAN: 49~57개 클러스터로 과분할
- 높은 2차원 실루엣과 낮은 NMI/ARI가 동시에 발생

따라서 본 프로젝트에서는 실루엣 하나보다 실제 의미 라벨과의 정합성 및 운용 가능한 구조를 우선했다.

### 5.3 약지도 UMAP의 가중치를 작게 둔 이유

클러스터 정보를 강하게 주면 결과가 실제 임베딩 구조보다 라벨을 복제하는 지도로 변할 수 있다. 실험 과정에서 높은 가중치는 클러스터 사이를 지나치게 벌렸다.

현재 기본 목표 가중치는 `0.01`이다. 소프트 소속도는 경계를 약하게 드러내는 힌트로만 사용하며, 원 임베딩의 이웃 관계가 주된 기하 구조를 결정하게 한다.

목표의 우선순위는 다음과 같다.

1. 계층형 경로 소속도
2. 평면 소프트 소속도
3. 소프트 정보가 없을 때 범주형 하드 라벨

### 5.4 군집화와 시각화의 PCA 차원을 분리한 이유

군집화는 가능한 많은 의미 정보를 보존해야 하지만, 2차원 시각화는 UMAP 자체가 강한 병목이다. 따라서 두 작업에 같은 차원을 강제할 필요가 없다.

AG News 4,000개, 768차원 임베딩에서 다음 결과를 얻었다.

| PCA 차원 | 누적 설명분산 | 원본→PCA k=15 이웃 보존 | 원본→UMAP2 k=15 이웃 보존 |
|---:|---:|---:|---:|
| 16 | 31.86% | 36.51% | 21.59% |
| 32 | 45.28% | 53.12% | 28.59% |
| 64 | 61.51% | 68.14% | 31.20% |
| 128 | 78.92% | 80.82% | 32.33% |
| 256 | 92.89% | 87.17% | 32.36% |

PCA 차원을 64에서 256으로 올리면 PCA 공간의 이웃 보존은 크게 증가하지만, 최종 UMAP2의 이웃 보존은 약 1.2%p만 증가한다. 따라서 다음 방향이 합리적이다.

- 군집화: 정보 보존을 위해 PCA256 검토
- 시각화: 비용 대비 효율이 좋은 PCA64 유지

단, 이 값은 특정 데이터와 임베딩 모델에서 얻은 결과다. 데이터가 바뀌면 동일한 평가 절차를 다시 수행해야 한다.

## 6. 실험과 평가

### 6.1 군집 파이프라인 비교

| 파이프라인 | NMI | ARI | 클러스터 수 | 노이즈 | 실행시간 | 결과 해석 |
|---|---:|---:|---:|---:|---:|---|
| 원시 FCM | 0.3428 | 0.2693 | 3 | 0% | 0.91초 | PCA 없이 의미 분리 부족 |
| **PCA64 + FCM** | **0.5651** | **0.5998** | **4** | **0%** | **0.92초** | 가장 균형적인 결과 |
| PCA64 + HDBSCAN | 0.3082 | 0.2039 | 2 | 39.0% | 1.99초 | 많은 표본을 노이즈로 처리 |
| PCA50 → UMAP2 → HDBSCAN | 0.3418 | 0.0777 | 57 | 19.8% | 25.28초 | 높은 과분할 |
| UMAP8 → HDBSCAN | 0.3286 | 0.0619 | 53 | 28.1% | 31.96초 | 국소 구조가 의미 라벨을 파편화 |

이 결과는 높은 실루엣이 항상 좋은 의미 군집을 뜻하지 않는다는 점을 보여준다. UMAP 공간에서 작은 클러스터가 잘 분리되어도 원래 문서 주제가 여러 조각으로 찢어질 수 있다.

### 6.2 소프트 클러스터링 대안 비교

PCA64+GMM은 NMI `0.4967`, ARI `0.4137`을 기록했다. 소프트 소속도를 제공한다는 장점은 확인했지만, PCA64+FCM보다 외부 라벨 정합성이 낮아 최종 핵심 알고리즘으로 선택하지 않았다.

### 6.3 증분 처리 검증

AG News 데이터의 각 라벨에서 10%씩 분리하여 초기 90%와 신규 10%가 같은 클래스 비율을 갖도록 구성했다.

- 초기 데이터: 3,600개
- 신규 배치: 400개
- 신규 노이즈: 0.75%
- 당시 기본 재군집 기준: 30% (현재 기본값은 5%)
- 결과: 기존 모델과 좌표 유지

별도로 임계값을 낮춰 전체 재군집 경로도 검증했다.

### 6.4 PCA 차원 선택 검증

PCA16/32/64를 시드 11, 42, 73에서 반복 평가했다.

- 주 지표: 원본 임베딩과 UMAP2의 k-NN 겹침
- 보조 지표: 전역 거리 스피어만 상관
- 안정성 지표: 시드 간 UMAP 이웃 그래프 Jaccard
- 진단 지표: PCA 설명분산 및 UMAP 이전 이웃 보존

64차원이 지역 이웃 보존에서 가장 좋았지만, 전역 거리 상관과 시드 안정성은 16차원이 더 높았다. 모든 1표준오차 기준을 동시에 만족한 후보는 없었으며, 시각화의 주 목적인 국소 이웃 보존을 우선해 64차원을 선택했다.

따라서 PCA64는 모든 지표의 절대적 우승값이 아니라 **선택한 목적 함수에 따른 절충**이다.

## 7. 프로젝트의 차별점과 기여

### 7.1 소프트 소속도를 부가 정보가 아닌 핵심 데이터로 취급

일반적인 시각화 시스템은 하드 클러스터 ID만 저장하는 경우가 많다. 본 프로젝트는 각 문서의 전체 소속도와 계층별 경로 소속도를 보존한다.

### 7.2 계층 소속도의 확률적 일관성 확보

서로 다른 부모에서 계산된 지역 소속도를 그대로 비교하지 않고, 부모 확률과 조건부 소속도를 곱해 전역 경로 확률을 구성했다.

### 7.3 군집 품질과 시각적 품질의 분리

UMAP의 2차원 분리도를 군집 품질로 오인하지 않고, 고차원 군집화와 2차원 표현을 독립적으로 평가했다.

### 7.4 안정적인 증분 시각화

신규 데이터 추가 시 기존 좌표를 고정하여 사용자가 이미 학습한 공간 관계를 유지한다. 노이즈 비율을 분포 변화 신호로 사용하여 안정성과 최신성을 절충했다.

### 7.5 실험 결과를 구현 사양으로 전환

Python 실험에 그치지 않고 알고리즘, 자료형, 입력 검증, CLI, 시각화와 완료 기준을 JS/TS 이식 문서로 정리했다.

## 10. 한계와 향후 개선 방향

### 10.1 데이터셋 일반화 검증 부족

핵심 수치의 상당 부분이 AG News 4,000개와 특정 768차원 임베딩에서 나왔다. DBpedia와 다른 임베딩 모델에서도 같은 경향이 유지되는지 검증해야 한다.

### 10.2 약지도 시각화의 순환논증 가능성

클러스터 결과를 UMAP 목표로 사용한 그림을 다시 클러스터 성능의 증거로 사용하면 안 된다. 평가용 비지도 시각화와 사용자 탐색용 약지도 시각화를 분리할 필요가 있다.

### 10.3 좌표 안정성과 최신 구조 표현의 충돌

좌표를 계속 고정하면 심상 지도는 유지되지만 재군집된 구조를 가장 잘 표현하지 못할 수 있다. 전체 시각화 재학습 조건도 별도로 설계할 필요가 있다.

### 10.4 고정 임계값의 데이터 의존성

PCA 차원, 소속도 임계값, 최소 노드 크기와 노이즈 5% 및 XB 악화 5%
기준은 데이터에 따라 달라질 수 있다. 데이터 규모와 분포에 따른 자동 보정이
필요하다.

### 10.5 소프트 군집 평가 지표 보강

NMI와 ARI는 하드 라벨 중심의 지표다. 향후에는 퍼지 분할 계수, 분할 엔트로피, 보정, 계층 일관성 지표를 함께 평가할 수 있다.

### 10.6 저장소 제품화 정리

현재 저장소는 실험 산출물이 많고 공식 테스트 모음, 의존성 명세와 사용자 README가 부족하다. 데이터와 생성 결과를 코드에서 분리하고 재현 가능한 실험 설정을 정리해야 한다.

## 11. 예상 질문과 답변

### Q1. 왜 K-Means 대신 FCM을 사용했는가?

K-Means는 각 문서를 하나의 클러스터에만 배정한다. 본 프로젝트는 여러 주제에 걸친 문서의 모호성을 보존하는 것이 핵심이므로 전체 소속도를 제공하는 FCM을 선택했다. 또한 PCA64+FCM이 비교 실험에서 가장 높은 NMI와 ARI를 기록했다.

### Q2. 왜 코사인 거리를 직접 사용하지 않고 유클리드 거리를 사용했는가?

입력과 중심을 모두 L2 정규화하면 단위 구면에서 두 거리의 순위가 대응한다. 각 반복에서 중심을 다시 정규화하여 방향 기반 의미 공간을 유지하면서 구현을 단순화했다.

### Q3. 실루엣이 더 높은 HDBSCAN을 선택하지 않은 이유는 무엇인가?

UMAP+HDBSCAN은 높은 실루엣을 보였지만 49~57개 클러스터로 과분할되었고 NMI와 ARI는 낮았다. 즉 2차원에서 잘 떨어진 작은 집단이 실제 의미 라벨과 잘 대응하지 않았다. 본 프로젝트는 단일 지표보다 의미 정합성, 노이즈와 운용 가능한 클러스터 수를 함께 고려했다.

### Q4. 클러스터 수를 사전에 정해야 하는 FCM으로 계층 구조를 어떻게 만들었는가?

각 계층 노드에서 여러 `k` 후보를 독립적으로 실행하고 XB 50%·PC 25%·PE 25% 순위점수로 선택한다. XB가 처음 악화된 뒤 두 후보를 더 확인하며, 표본 수가 부족하면 그 노드에서는 재귀를 중단한다.

### Q5. 서로 다른 부모 아래의 소속도를 비교할 수 있는가?

지역 소속도는 각 부모 내부에서 계산되므로 직접 비교하면 안 된다. 본 프로젝트는 부모까지의 경로 확률과 현재 조건부 소속도를 곱해 같은 깊이의 전역 경로 확률을 만든다.

### Q6. UMAP에 클러스터 정보를 넣으면 결과를 조작하는 것 아닌가?

그 위험이 있으므로 가중치를 `0.01`로 매우 작게 설정했다. 목적은 클러스터를 강제로 분리하는 것이 아니라 경계를 약하게 보조하는 것이다. 성능 평가는 약지도 그림의 모양이 아니라 원공간 지표와 이웃 보존을 기준으로 한다.

### Q7. 왜 군집화와 시각화에 다른 PCA 차원을 쓰는가?

군집화에서는 고차원 정보 보존이 중요하지만, 시각화는 최종적으로 2차원 UMAP을 거친다. PCA64 이후에는 차원을 더 늘려도 최종 2차원 이웃 보존 개선이 작았다. 따라서 시각화는 PCA64로 비용을 줄이고, 군집화는 PCA256의 효과를 추가 검증하는 방향이다.

### Q8. 신규 데이터가 기존 분포와 완전히 다르면 어떻게 되는가?

기존 중심에 잘 배정되지 않는 문서는 노이즈가 된다. 신규 배치의 노이즈 비율이 임계값을 넘으면 누적 데이터 전체를 다시 군집화한다. 따라서 작은 변화에는 안정성을 유지하고 큰 분포 변화에는 모델을 갱신한다.

### Q9. 기존 좌표를 고정하면 재군집 결과와 맞지 않을 수 있지 않은가?

맞다. 이는 정확한 최신 배치와 사용자의 심상 지도 사이의 절충이다. 현재는 위치 안정성을 우선했으며, 향후에는 분포 변화나 클러스터 변경률을 기준으로 전체 시각화까지 재학습하는 정책이 필요하다.

### Q10. 이 프로젝트의 가장 큰 기술적 기여는 무엇인가?

개별 알고리즘의 발명보다는 여러 기술을 일관된 의미 모델로 결합한 점이다. 구면 FCM의 소프트 소속도를 계층형 조건부 경로 확률로 확장하고, 이를 약지도 시각화와 고정 좌표 증분 업데이트까지 연결했다.

## 12. 결론

본 프로젝트는 텍스트 임베딩을 단순히 클러스터 번호로 압축하지 않고, 문서의 애매한 주제 소속과 계층 관계를 보존하는 방향으로 발전했다.

핵심 설계는 다음과 같다.

1. L2 정규화와 구면 FCM으로 방향 기반 의미 공간을 유지한다.
2. 소프트 소속도를 핵심 결과로 저장한다.
3. 각 노드의 데이터가 지지하는 경우에만 계층을 확장한다.
4. 조건부 경로 소속도로 계층 확률을 일관되게 표현한다.
5. 시각화는 약하게만 유도하고 원공간 이웃 구조를 우선한다.
6. 신규 데이터에는 좌표 안정성을 유지하되 노이즈 증가를 분포 변화 신호로 사용한다.
7. 알고리즘과 파라미터 선택을 정량 실험으로 설명한다.

최종적으로 본 프로젝트가 해결하려는 질문은 다음과 같다.
